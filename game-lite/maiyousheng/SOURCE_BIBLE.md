# SOURCE_BIBLE · 卖油翁（30 行内）

## 玩家动词（原文证据）

1. 射（「尝射于家圃」）→ 第一幕：时机判定射箭
2. 睨之（「睨之久而不去」）→ 观看/注视：翁的凝视作为常驻反馈
3. 微颔之（「但微颔之」）→ 评价机制：无论中多少，翁只微颔
4. 问与答（「汝亦知射乎」「无他，但手熟尔」）→ 幕间对话推进
5. 忿然（「尔安敢轻吾射！」）→ 冲突升级，转入第二幕
6. 酌油（「徐以杓酌油沥之」）→ 第二幕：节制倾倒，「徐」是操作指令
7. 笑而遣之（「康肃笑而遣之」）→ 结局：被说服后的释然

## 空间序列

家圃（射箭场地）→ 对话对峙（同一场景推近）→ 葫芦/铜钱/杓陈列（地上一角）→ 释然收场。单场景四拍，情绪曲线：自矜 → 被质疑 → 忿然 → 服气。

## 世界规则

- 「发矢十中八九」：射术上限就是十中八九，不是十中十 → 中 8-9 支属「正常发挥」，完美主义被文本否定。
- 「但微颔之」：翁的评价恒定，不因神射加码 → 玩家打得再好也只换点头。
- 「徐以杓」：慢 = 稳 → 第二幕的操作说明书。
- 「自钱孔入，而钱不湿」：通过方孔判定的硬标准 → 油流必须过孔，擦边即湿。
- 「我亦无他，惟手熟尔」：熟 = 练出来的 → 重试本身应该让玩家变强（手熟度机制）。

## 视觉锚点

家圃箭靶（同心环）、释担而立的翁与油担、忿然的康肃、覆在葫芦口的铜钱方孔、金色细油流、钱上不沾的圆珠水光。

## 改编边界

不加战斗/加时/商店；两幕难度关系必须成立：酌油比射箭更精（油比箭难控），这正是论点本体。
