# GAME_DESIGN · 卖油翁：惟手熟尔（20 行内）

- 模板：点击解谜（主：时机判定）+ 抉择叙事（幕间对话）。核心情绪：服气。
- 幕一·射箭：准星在家圃靶上利萨茹游走，点击/空格放箭，10 支计环（红心中/近/擦/脱）。
  文本规则锁死：无论打多好，翁只「微颔之」（动画恒定）；打完触发对峙对话四连。
- 幕二·酌油：按住倾倒，油流落点 = 杓口 + 摆幅；摆幅随单次按住时长增大（手抖），
  「徐以杓」= 点射短倒。落进钱方孔（±12px）葫芦增液；擦到钱面 → 钱湿，翁重来。
- 手熟机制（签名）：每次钱湿后手熟 +1，基础摆幅永久减小——**重试让玩家真的变强**，
  玩通那一刻就是亲手验证「惟手熟尔」。葫芦注满即通关。
- 结局卷轴：行迹（中矢 X/10 · 沥油 N 注 · 钱湿 M 次 · 手熟 Lv）+ 「我亦无他，惟手熟尔」
  + 若中矢=10 加一行「翁亦只是微颔——神射亦无他」。
- 双输入：鼠标按住/空格按住均可；手机竖屏点击兜底（按住即倒）。
- 原文锚点：每幕 footer 常驻引文；机制触发时台词即锚点。
- 预算：单文件 <300KB、零依赖、canvas 2D、程序化水墨（与桃花源记同族画风）。
