# 示例 · 卖油翁：惟手熟尔

**双击 [index.html](index.html) 即玩**（24KB，零依赖，离线可玩）。点击放箭 · 按住斟油（短点更稳）。

《卖油翁》（欧阳修，公版）×「点击解谜」模板——双幕时机判定，把课文论点做成了玩法本体：

- **幕一·射箭**：准星游走，十矢计环。但无论十中几，翁都只「但微颔之」——原文的评价制度原样生效。
- **幕二·酌油**：按住倾倒，油流摆幅随按住时长变大，「徐以杓」= 短点慢倒。落进钱方孔则葫芦增液，擦到钱面即「钱湿」，翁不愠，徐徐更酌。
- **手熟机制（签名）**：每次钱湿，手熟 +1，摆幅永久变小——**重试真的让你变强**。玩通的那一刻，你亲手验证了「惟手熟尔」。

## 机制 ↔ 原文对应

| 玩法 | 原文锚点 |
| --- | --- |
| 射十矢计环 | 「见其发矢十中八九，但微颔之」 |
| 评价恒定不加分 | 「无他，但手熟尔」 |
| 短点慢倒才稳 | 「徐以杓酌油沥之」 |
| 钱方孔判定 | 「自钱孔入，而钱不湿」 |
| 湿了重来、越练越稳 | 「我亦无他，惟手熟尔」 |
| 结局释然 | 「康肃笑而遣之」 |
