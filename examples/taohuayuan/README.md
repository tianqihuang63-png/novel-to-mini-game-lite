# 示例 · 桃花源记：寻向所志

**双击 [index.html](index.html) 即玩**（26KB，零依赖，离线可玩）。方向键移动 · E 交互 · X 标记。

《桃花源记》（陶渊明，公版）×「收集探索」模板 ×「抉择叙事」终局——一次会话内完成的完整示例，
用来展示本技能的三步产物长什么样。

## 玩法与原文的对应关系（签名卖点演示）

| 玩法机制 | 原文锚点 |
| --- | --- |
| 拾 5 片落英，山口亮起 | 「忽逢桃花林……落英缤纷」「山有小口，仿佛若有光」 |
| 狭道压缩→豁然开朗转场 | 「初极狭，才通人。复行数十步，豁然开朗」 |
| 走访 3 位村民 + 「今是何世」二选一 | 「便要还家，设酒杀鸡作食」「乃不知有汉，无论魏晋」 |
| 系丝带做记号（处处志之） | 「便扶向路，处处志之」 |
| 守口结局：桃源长存 | 「不足为外人道也」 |
| 告密结局：寻向所志，遂迷 | 「寻向所志，遂迷，不复得路。……后遂无问津者」 |

设计核心：原著里「靠标记反而找不到路」是制度性事实，所以丝带**故意不提供寻路能力**——
宿命做进制度，不做成败惩罚。玩家真正拥有的选择只有一个：说，还是不说。

## 三步工作区（本技能产出的文档形态）

三份文档极简到可以贴进课程页，这就是 Lite 与原版七阶段的最大区别：

**PRODUCT_BRIEF（10 行内）**：公版文本；浏览器单文件；5-8 分钟；narrative-led；中文界面；
全年龄；无存档无音频（假设已确认）。

**SOURCE_BIBLE（30 行内）**：玩家动词 6 条（行/异之/具答之/停数日辞去/处处志之/诣太守）；
空间序列 5 段（溪→林→洞→村→返）；世界规则 5 条（光引路/极狭豁然/隔绝/志之必迷/诫命）；
视觉锚点（桃林落英/山口一点光/屋舍俨然/水墨远山）——每条均带原文引用。

**GAME_DESIGN（20 行内）**：模板=收集探索（主）+抉择叙事（终局）；核心情绪=豁然开朗；
不可逆选择=诣太守说 vs 守口；行迹统计=落英/天数/丝带/村中选择；预算=26KB/零依赖/60fps。
