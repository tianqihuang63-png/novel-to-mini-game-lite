# 手机党 5 卡：不装任何工具，网页 AI 就能把课文变游戏

给无法运行 Claude Code / Codex 等命令行工具的用户（手机、平板、老电脑均可）。
用任意网页版 AI（豆包 / Kimi / 腾讯元宝 / 通义）按顺序粘贴下面 5 张卡，每张等它回完再发下一张。
全程免费额度可完成；产出同样是一个单文件 HTML。

> 使用前确认：你要改编的文本是公版（作者去世超 50 年的课文/古籍），或你拥有授权。

---

## 第 1 卡 · 速拆

```text
你是轻量小说游戏化导演。通读下面这篇《文本标题/粘贴全文》，只提取四样东西，每条都附原文引用，总共不超过 30 行，不要夸奖原文：
1. 玩家动词：主角做了什么（走/收/问/选/藏）
2. 空间序列：场景先后顺序
3. 世界规则：因果与限制（尤其是结局性的）
4. 视觉锚点：画面感最强的 3-5 个意象
文本：【粘贴全文】
```

## 第 2 卡 · 定向

```text
从这五个模板里选一个最适合它的，只选一个并给出一句话理由：收集探索 / 抉择叙事 / 文字冒险 / 点击解谜 / 卡片抉择。
然后按你选的模板给出设计，不超过 20 行：核心情绪一句话、3-4 个场景、玩家按键动词、一个不可逆选择、两个结局的方向、行迹统计项。
```

## 第 3 卡 · 锁预算

```text
给这个游戏加低配预算约束，输出一份「构建说明」：
单文件HTML、零依赖零外链、canvas 2D 禁 WebGL、全部画面程序化绘制、中文系统衬线字体、体积小于300KB、键盘加点击双输入、手机竖屏可玩、每个机制旁边显示对应的原文小字。
把上面的设计翻译成这份构建说明里的场景清单和交互清单，不要写代码。
```

## 第 4 卡 · 生成代码

```text
按构建说明写出完整的单文件 index.html。要求：
1. 一次给全，不要省略号；如果太长，从「<!DOCTYPE html>」开始按顺序输出，我说「继续」你再接着写
2. 所有画面用代码画（渐变/贝塞尔/椭圆/剪影），不用任何图片和外部资源
3. 状态机管理场景；中文文案；对话用逐字浮现
4. 文件末尾留一行注释统计：预计体积
现在开始。
```

## 第 5 卡 · 自检

```text
自查刚才的代码，如实回答（不过就说不过）：
1. 六项验收：能启动？每场景能渲染？键盘和点击都生效？闭环能通？结局能到？能重开？
2. 有没有用到外部链接、图片、WebGL、setInterval 驱动逻辑？有的话改掉
3. 每个机制旁有没有原文小字？缺哪几处，直接给出修改后的完整代码段
4. 用手机浏览器打开 file.html 的操作步骤写给我
```

---

## 组装与游玩

1. 把 AI 给的代码全选复制，用手机备忘录或任意文本编辑器粘贴，存为 `index.html`（UTF-8）。
2. 传到电脑双击打开；或手机直接用「文件」App 打开 → 选择浏览器打开。
3. 玩不通就把报错截图/现象描述发回给 AI，附一句：「按第 5 卡的第 1 条修，只给修改的代码段」。

## 常见翻车与自救

| 现象 | 一句话修复指令 |
| --- | --- |
| 页面全黑/白屏 | 「console 报错是什么，给出修复后的完整代码」 |
| 电脑能玩手机不能 | 「把键盘事件补上点击按钮兜底，竖屏布局自适应」 |
| 越玩越卡 | 「检查每帧新建渐变和不回收的粒子，给出修复段」 |
| 字太小 | 「正文等效字号提到 16px 以上，行距 1.6」 |
