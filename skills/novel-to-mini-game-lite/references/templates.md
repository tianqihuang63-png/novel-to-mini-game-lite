# 五大游戏模板（templates.md）

定向时只许从这五个里选。每个模板 = 一种文本气质 × 一套核心动词 × 一个现成结构。
选模板的判断标准只有一个：**哪种动词最能放大这段文本的核心情绪**。

## 1. 收集探索（Collect & Explore）

- 适合：风景/植物/物件意象密集的文本。桃花源记、故乡的杨梅、北平的秋。
- 核心动词：移动 → 拾取 → 找入口。
- 现成结构：横向卷轴 3-4 幕；拾满 N 件意象物 → 出口亮起 → 穿过入口转场。
- 情绪放大器：转场做「压缩→释放」（狭道黑屏后豁然开朗）。
- 结局卷轴：行迹统计 + 原文金句。
- 参考：examples/taohuayuan 整个就是这个模板。

## 2. 抉择叙事（Choice & Consequence）

- 适合：有道德两难或命运转折的文本。鸿门宴、背影（送不送）、我的叔叔于勒。
- 核心动词：对话 → 承诺 → 结算。
- 现成结构：走访 2-3 个角色收集信息 → 一个不可逆二选一 → 双结局卷轴。
- 情绪放大器：把原文的「制度性事实」做成机制（如「寻向所志，遂迷」= 标记必然失效）。
- 要点：选择必须有真实因果差（台词、色调、统计至少两样不同）。

## 3. 文字冒险（Interactive Fiction）

- 适合：对话和心理描写多、场景少的文本。家书、口述史、访谈实录。
- 核心动词：阅读 → 分支 → 回响。
- 现成结构：节点树 15-25 个节点封顶；每节点 ≤ 60 字；3 个回响变量在结局收束。
- 情绪放大器：回响——早期的小选择在结局卷轴里被点名（「你当时没接话，后来……」）。
- 要点：无图的纯文字版允许 DOM 排版，但对比度与大字号仍须达标。

## 4. 点击解谜（Point & Click Puzzle）

- 适合：有机关、信物、暗号的文本。口技、核舟记、盗墓笔记片段（需授权）。
- 核心动词：观察 → 组合 → 开锁。
- 现成结构：单屏 5-8 个可点热区；2-3 道锁；每把锁的线索在原文里有出处。
- 情绪放大器：锁开时的原文引用逐字浮现。
- 要点：卡死保护——连续 3 次错误后高亮下一个可点热区。

## 5. 卡片抉择（Card Deliberation）

- 适合：事理博弈、比价、劝说的文本。邹忌讽齐王纳谏、烛之武退秦师、职场择业帖。
- 核心动词：出牌 → 权衡 → 定局。
- 现成结构：手牌 5 张（每张 = 原文里的一个论据/筹码）→ 对手 3 轮应对 → 结局按论点命中数结算。
- 情绪放大器：每张牌打出时显示它出自原文哪一句。
- 要点：数值只有一维（说服度/胜算），别做资源管理。

## 选用速查

| 文本里最多的是…… | 选 |
| --- | --- |
| 景物和物件 | 收集探索 |
| 两难和转折 | 抉择叙事 |
| 对白和心声 | 文字冒险 |
| 机关和信物 | 点击解谜 |
| 论据和博弈 | 卡片抉择 |

五个模板共用一个签名规范：**机制旁小字原文锚点**。玩家每触发一个机制，
屏幕角落浮现对应的原文句子——这是「有原著依据」最直观的证明，不许删。
