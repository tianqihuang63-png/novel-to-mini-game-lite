# 低配预算契约（budget.md）

低配用户的三个真实瓶颈：token 预算、会话长度、产出物性能。本契约只管第三条，
前两条由「三步流程 + 文档行数上限」解决。违反任何一条硬指标即返工，不协商。

## 成品硬指标

| 项 | 上限/要求 | 为什么 |
| --- | --- | --- |
| 文件数 | 1 个 `index.html` | 双击即玩，不发也永不过期 |
| 体积 | < 300KB（目标 100-200KB） | 微信里传得动，老手机秒开 |
| 依赖 | 0（无 CDN、无字体文件、无图片、无音频文件） | 离线可玩，断网不残废 |
| 构建 | 0（不引入打包器、框架、npm） | 低配机器跑不动 node 工具链 |
| 渲染 | canvas 2D / DOM/CSS，禁 WebGL、禁视频纹理 | 核显与老款手机 GPU 才能扛 |
| 帧率 | 中端核显 60fps；粒子同一屏 ≤ 80 个 | 粒子是性能第一杀手 |
| 请求 | 运行时零网络请求 | file:// 协议下也不能报错 |
| 输入 | 键盘 + 点击双通道，竖屏可玩 | 手机党是默认受众 |
| 内容 | 全年龄；文字对比度 ≥ 4.5:1；不单靠颜色传义 | 长辈和色弱用户 |

## 实现手法白名单（照做最省性能）

- 全部视觉程序化绘制：渐变、贝塞尔山形、椭圆花瓣、矩形屋舍、剪影人形
- 中文字体用系统衬线栈：`"Kaiti SC","STKaiti","KaiTi","Songti SC","SimSun",serif`
- 动画统一 `requestAnimationFrame`，单主循环，dt 钳制（≤ 50ms）防切页暴走
- 状态机管理场景，禁止多定时器打架
- 粒子复用数组、出屏回收；离屏不画

## 禁止清单

- 禁：`<img>` 外链、base64 大图、音视频文件、localStorage 存档（隐私合规省事）
- 禁：CSS 滤镜/阴影大面积叠加（低端 GPU 掉帧主因）
- 禁：每帧新建渐变对象——渐变在场景 `enter()` 时缓存
- 禁：`setInterval` 驱动游戏逻辑

## 自检与证据

写完必须真跑一遍，在 `SELF-CHECK.md` 如实记录（不过就写不过，禁止包装成过）：

```text
launch   □ 页面加载无报错（console 干净）
render   □ 每个场景截图正常、无破图无占位
input    □ 键盘与点击都实测生效
coreLoop □ 完整闭环 ≥ 1 轮
outcome  □ 至少 1 个结局达成（有双结局就都验）
restart  □ 重开回到初始态，旧状态清干净
size     □ ls -l 实测体积 ___KB（<300）
```

证据标准：每项写「怎么验的、看到什么」。跑不了的就标 NOT_RUN，不许写 PASS。
